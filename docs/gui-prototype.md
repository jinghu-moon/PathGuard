# LSPosed GUI 交互原型（方案 B）

目标：提供 **可视化规则管理**、**即时校验**、**热重载** 与 **日志查看**，不触碰热路径逻辑。GUI 只负责编辑与触发重载。

## 1. 入口与导航

- **入口**：LSPosed 管理器 → 模块设置页（单 Activity）
- **导航结构**：单 Activity + 顶部 Tabs（或底部导航）
  - 规则
  - 预览
  - 日志
  - 关于

## 2. 页面结构

### 2.1 规则首页（应用列表）

**目的**：快速查看每个应用的模式、启用状态、规则数量。

**列表项内容**
- 应用图标 + 包名
- `mode`（黑/白名单）
- `enabled` 开关
- 规则数：`allow / deny / redirect / delete`
- 最近修改时间

**操作**
- 点击进入应用详情
- 搜索框（包名 / 应用名）
- “新增应用规则”按钮（选择已安装应用 → 自动创建分组）

### 2.2 应用详情页（规则分组编辑）

**顶部配置**
- `mode`：黑名单 / 白名单（必选）
- `enabled`：开关
- 删除策略：`delete_existing` / `delete_dirs`

**规则区块（按类型分组）**
- ✅ 允许 `+`
- 🚫 禁止 `-`
- 🧹 删除 `!`
- 🔁 静态重定向 `->`
- 🌀 动态重定向 `=>`

**列表项显示**
- 原路径（高亮 glob）
- 目标路径（重定向时）
- `@types`（如存在）
- 简短备注（可选）

**操作**
- 新增规则（浮动按钮）
- 编辑 / 删除 / 复制
- 拖动排序（可选，默认按规则优先级排序显示）

### 2.3 规则编辑页（单条）

**字段**
- 类型选择：`+ / - / ! / -> / =>`
- 路径输入（自动补全 `/storage/emulated/0/`）
- 目标路径（仅 `->` / `=>`）
- `@types`（仅 `->` / `=>`）
- 备注（可选）

**快速辅助**
- 常用目录快捷插入（DCIM、Pictures、Download、Movies）
- 通配符助手：`*` / `?` / `**` 说明与示例
- “预览归一化路径”（展示最终写入的绝对路径）

### 2.4 预览页（最终 rules.ini）

**目的**：用户可直接看到最终写入文件内容。

**功能**
- 只读渲染 `rules.ini`
- “复制到剪贴板”
- “导出到文件”

### 2.5 日志页（排错）

**来源**
- `/data/adb/modules/folder_manager/run/daemon.log`
- `/data/adb/modules/folder_manager/run/service.log`

**功能**
- 选择日志类型（守护进程 / service）
- 搜索过滤（关键字）
- 复制 / 导出

## 3. 保存流程（关键交互）

1. 用户点击“保存”
2. GUI 调用规则解析（JNI / 内置 C++ 解析器）
3. 若有错误 → 显示 **行号 + 原因**
4. 校验通过 → 写入 `rules.ini`（临时文件 + 原子替换）
5. 调用热重载：`/data/adb/modules/folder_manager/bin/reload.sh`
6. Toast 提示：`规则已生效`

## 4. 验证与提示文案

- **语法错误**：`第 12 行：重定向目标不可包含通配符`
- **缺少 mode**：`[com.xxx] 缺少 mode，必须显式声明`
- **路径为空**：`路径不能为空`
- **重定向缺目标**：`-> / => 规则必须填写目标路径`
- **types 非法**：`@types 仅允许字母/数字/逗号`

## 5. 规则模板（内置）

提供内置模板，作为新手入口：

- 微信白名单模板
- QQ 白名单模板
- 图片重定向模板
- 删除缓存模板
